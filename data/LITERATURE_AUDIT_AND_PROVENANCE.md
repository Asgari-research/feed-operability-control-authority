# Literature audit and provenance 

## Primary nominal process evidence

Nguyen et al., Chemical Engineering Journal 452 (2023) 139550, DOI 10.1016/j.cej.2022.139550. Primary evidence used for the dry 15/85 feed, experimental CALF-20 VSA/LPP context, ~70 g total adsorbent context, and headline LPP 95.5% purity / 88.1% recovery. Exact point-specific operating values that were not verified in accessible primary numerical text remain blank.

## Supporting-information locator

The open preprint lineage, DOI 10.26434/chemrxiv-2022-c7hp1, explicitly states that SI contains experimental and simulated transients for Experiments I–IX, a PVSA rig image, DSL parameters and measured-isotherm plots. analysis records this as a future auditable digitization target; it does not invent numerical trace coordinates.

## Same-platform cyclic validation

Nguyen et al., Adsorption 31 (2025), DOI 10.1007/s10450-025-00600-z, correction DOI 10.1007/s10450-025-00628-1. Explicitly tabulated dry A0/B0 cases are used as independent same-platform CSS validation targets.

## Independent pilot evidence / same-platform context

Wilkins et al., Chemical Engineering Journal 532 (2026) 174238, DOI 10.1016/j.cej.2026.174238. The 75-run pilot campaign remains independent process evidence; its later description of the earlier packed-bed platform supplies secondary geometry/context only. Approximately 36 g per column is consistent with the ~70 g total two-column primary context.

## Transport evidence

Tang et al., Industrial & Engineering Chemistry Research (2025), DOI 10.1021/acs.iecr.5c02322. Independent CALF-20 ZLC transport evidence is used to define a transport prior; any LDF conversion is labelled as a derived mapping.

## Provenance principle

Every active numerical value is assigned an evidence role such as primary experiment, secondary same-platform context, independent validation, deterministic reconstruction, derived physics relation or engineering prior. The code/data audit prevents CSS priors/configurations from being counted as completed CSS results.
