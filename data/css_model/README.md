# P10 publication-closure CSS model inputs

This folder contains **model inputs and validation targets**, not completed CSS results.

* `Nguyen2025_same_rig_dry_validation_cases.csv` — two peer-reviewed dry VSA/LPP cases (A0/B0) used as independent same-platform cyclic validation targets.
* `CALF20_css_model_priors.csv` — geometry/transport/thermal parameters with explicit evidence roles. Values labelled model priors are not experimental facts.
* `CALF20_css_validation_requirements.csv` — predeclared validation gates.

Actual solver outputs are written to the designated results folder under `validation/css_*`; they are never stored here and are never counted as literature evidence.
