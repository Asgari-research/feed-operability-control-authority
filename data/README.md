# Data and provenance

`input_folder` contains the parser-ready equilibrium and process-anchor inputs used by the main pipeline. The other folders contain supporting literature evidence, independent parameterizations, pilot-scale validation data, engineering assumptions, CSS validation targets and schema templates.

The package distinguishes measured, transcribed, reconstructed and assumed quantities. Literature identifiers and evidence roles are recorded in the reference registry and audit tables. Files labelled `DO_NOT_COPY_TO_INPUT` are contextual or audit records rather than parser-ready primary inputs.
