# Nguyen et al. 2025 — same-platform dry/humid CALF-20 VSA validation

**DOI:** 10.1007/s10450-025-00600-z  
**Correction:** 10.1007/s10450-025-00628-1

Role in P10: independent same-platform cyclic validation targets for the CSS solver.

The analysis records only the explicitly tabulated dry A0/B0 quantities used by the validation suite: feed composition, high/intermediate/low pressures, adsorption time, feed superficial velocity, purity, recovery and productivity. These rows are stored in `data/css_model/Nguyen2025_same_rig_dry_validation_cases.csv`.

The validation cases are not used to tune the reduced-order composition boundaries. They are used only to ask whether the high-fidelity cyclic model is credible enough to act as cross-fidelity falsification evidence.
