# Breakthrough-trace digitization protocol

Published dry CO2/N2 breakthrough experiments at approximately 5/95, 15/85 and 30/70 feed composition provide useful composition-resolved kinetic evidence. If trace coordinates are digitized from the paper or supporting information:

1. Record the DOI, figure/panel, axes, units, composition, temperature and pressure.
2. Preserve the source image or file separately and record a checksum.
3. Retain pixel-to-axis calibration and extraction metadata.
4. Repeat the extraction or otherwise estimate digitization uncertainty.
5. Report the values as digitized published data, not raw experimental measurements.
6. Propagate digitization uncertainty to t10/t50/t90 and front-width metrics.

The supplied audit template can be used to record the extraction metadata.
