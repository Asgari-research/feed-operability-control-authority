# Supporting-table numbering

The final submission uses one contiguous supporting-table sequence (S1–S59). Eight inherited zero-row placeholder families were removed from active SI and are retained only under `repository_only/removed_empty_tables/` for auditability. The file `SI_TABLE_RENUMBERING_MAP.csv` records the exact legacy-to-final identifier mapping. Source-literature references such as “SI Table S1” were not renumbered because they refer to the cited publication, not to this submission.
